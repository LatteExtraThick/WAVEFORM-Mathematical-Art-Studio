WAVEFORM Windows packaging
===========================

1. Extract this project folder.
2. On Windows 10/11, install Python 3.10 or newer.
3. Double-click build_windows.bat.
4. Run dist\WAVEFORM\WAVEFORM.exe.
5. Optional: install Inno Setup and run ISCC.exe installer\WAVEFORM.iss to make Setup.exe.

The executable is built on Windows because PyInstaller does not cross-compile Windows apps from Linux.
